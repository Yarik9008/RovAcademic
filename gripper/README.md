# Gripper — контроллер манипулятора ROV

Прошивка управляет коллекторным DC-мотором захвата через H-мост **DRV8870**. Команда поступает в виде **RC-PWM** сигнала (длительность импульса). Датчик тока **INA219** (I2C) обеспечивает защиту от перегрузки.

## Платформа

| Параметр | Значение |
|----------|----------|
| МК | STM32F103C8T6 |
| Частота | 72 МГц |
| Framework | Arduino (STM32) |
| Загрузка | WCH-Link + OpenOCD (custom) |

## Распиновка

| Функция | Пин | Примечание |
|---------|-----|------------|
| PWM вход | PA7 | INPUT_PULLDOWN, прерывание CHANGE |
| Мотор IA | PA11 | ШИМ, DRV8870 |
| Мотор IB | PA12 | ШИМ, DRV8870 |
| I2C SDA | PB7 | INA219 |
| I2C SCL | PB6 | INA219 |
| UART TX | PA9 | телеметрия |
| UART RX | PA10 | телеметрия |
| LED | PC13 | мигание каждые 500 мс |

## Принцип работы

### Приём команды (PWM)

Прерывание `CHANGE` на `PA7` измеряет длительность положительного импульса (мкс). Валидный диапазон: **500–3000 мкс** (фильтрация). Управляющий диапазон: **900–2400 мкс**.

| Длительность импульса | Команда |
|-----------------------|---------|
| < 1400 мкс | Реверс (скорость -255) |
| 1400–1600 мкс | Стоп (мёртвая зона) |
| > 1600 мкс | Вперёд (скорость 255) |

Управление дискретное: мотор включается на полную скорость в одном из двух направлений или останавливается.

### Защита по току (INA219)

1. При включении мотора запускается задержка **1 секунда** (`MOTOR_START_DELAY_MS`) — пусковой ток не отслеживается.
2. После задержки ток сравнивается с порогом **280 мА** (`CURRENT_PROTECTION_THRESHOLD_MA`).
3. При превышении — мотор останавливается, выставляется флаг защиты.
4. Защита сбрасывается только при **смене направления** (оператор должен отпустить и нажать в другую сторону).

Если INA219 не найден при инициализации (`ina219.begin()` = false), прошивка работает без токовой защиты.

### Телеметрия (UART 115200)

Каждые **100 мс** (`DATA_PRINT_INTERVAL_MS`) в `Serial` (PA9/PA10) выводится строка:

```
Pulse: 1500us | I: 120.50mA | V: 5.02V | P: 605.1mW | Motor: 0 [OK]
```

Состояния: `[OK]` — норма, `[СТАРТ]` — задержка после пуска, `[ЗАЩИТА]` — перегрузка.

При смене команды мотора дополнительно выводится:

```
Motor: FORWARD (1700us)
```

## Ключевые параметры (`Config.h`)

| Параметр | Значение | Описание |
|----------|----------|----------|
| `PWM_DEADZONE_MIN_US` | 1400 мкс | нижняя граница мёртвой зоны |
| `PWM_DEADZONE_MAX_US` | 1600 мкс | верхняя граница мёртвой зоны |
| `CURRENT_PROTECTION_THRESHOLD_MA` | 280 мА | порог токовой защиты |
| `MOTOR_START_DELAY_MS` | 1000 мс | задержка перед включением защиты |
| `DEBOUNCE_US` | 10 мкс | фильтр дребезга на входе PWM |
| `MAIN_LOOP_INTERVAL_MS` | 20 мс | период основного цикла |
| `DATA_PRINT_INTERVAL_MS` | 100 мс | период вывода телеметрии |

## Отличие от управления захватом в `control_system`

В `control_system` захват — это **сервопривод** на пине PB0, управляемый серво-сигналом 1000–2000 мкс напрямую из миксера. Здесь (`gripper`) — **отдельный контроллер** для коллекторного мотора с H-мостом и токовой защитой, подключаемый через один PWM-канал.

## Зависимости

- [Adafruit INA219](https://github.com/adafruit/Adafruit_INA219) (`lib_deps` в `platformio.ini`)

## Сборка и прошивка

```bash
cd gripper
pio run              # сборка
pio run -t upload    # прошивка через WCH-Link (OpenOCD)
pio device monitor -b 115200
```

> В `platformio.ini` путь `build_dir` и `upload_command` привязаны к `C:/tmp/...` — при необходимости поправьте под свою систему.
