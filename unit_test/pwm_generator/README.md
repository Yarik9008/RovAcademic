# pwm_generator — тест сервопривода (STM32F446)

Минимальная прошивка: циклически задаёт положение сервопривода **1000 / 1500 / 2000 µs** с паузами по 5 с.

## Платформа

| Параметр | Значение |
| -------- | -------- |
| МК | **STM32F446RET6** (`genericSTM32F446RE`) |
| Framework | Arduino |
| Загрузка | **DFU** (`upload_protocol = dfu`) |

В `platformio.ini` задан свой `build_dir` под Windows; при необходимости поправьте путь.

## Подключение

| Сигнал | Пин |
| ------ | --- |
| Серво PWM | **PB1** |

Питание серво — согласно вашей схеме (часто отдельный BEC, общий GND с платой).

## Сборка

```bash
cd pwm_generator
pio run
pio run -t upload
```

## Поведение

По кругу: минимум → центр → максимум → центр, затем снова.
