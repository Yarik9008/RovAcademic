# pwm_test_nano — тест сервопривода (Arduino Nano)

Прошивка для **ATmega328** (Arduino Nano): плавное перемещение сервопривода между заданными положениями (диапазон импульсов 1200–1800 µs, шаг с настраиваемой задержкой).

## Платформа

| Параметр | Значение |
| -------- | -------- |
| Плата | `nanoatmega328` |
| Framework | Arduino |
| Библиотека | `Servo` |

В `platformio.ini` указан `upload_port` — замените на свой COM-порт.

## Подключение

Сигнал сервопривода — **цифровой пин D3** (`SERVO_PIN` в `src/main.cpp`).

## Сборка

```bash
cd pwm_test_nano
pio run
pio run -t upload
```

## Поведение

После старта — пауза в центре, затем цикл: движение к минимуму → к центру → к максимуму → к центру с задержками между этапами.
