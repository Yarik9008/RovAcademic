# rov_test_motor — четыре канала PWM для моторов (Arduino Nano)

Стендовый тест класса **ROVMotor**: четыре выхода ШИМ (как у серво/ESC) на пинах **D3, D5, D6, D9**. По таймеру циклически меняются сценарии: все вперёд 50 %, поворот влево/вправо дифференциалом, стоп. Лог в **Serial** (9600 бод).

## Платформа

| Параметр | Значение |
| -------- | -------- |
| Плата | `nanoatmega328` |
| Зависимости | `Servo` + локальные `include/ROVMotor.h` и др. |

## Подключение

Соответствие моторов пинам задаётся в `src/main.cpp` (`MOTOR_PINS[]`).

## Сборка

```bash
cd rov_test_motor
pio run
pio run -t upload
pio device monitor -b 9600
```

Назначение — проверка ESC/миксера на столе, без погружения.
