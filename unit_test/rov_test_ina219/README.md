# rov_test_ina219 — датчик тока/напряжения INA219

Чтение **INA219** по I2C и вывод напряжения шины, шунта, тока и мощности в **UART1** (`PA9`/`PA10`, 57600 бод). Мигание **PC13** синхронно с опросом.

## Платформа

| Параметр | Значение |
| -------- | -------- |
| Board | `genericSTM32F103C8` |
| Загрузка | **ST-Link** |
| Библиотека | `adafruit/Adafruit INA219` |

## Подключение

| Сигнал | Пин |
| ------ | --- |
| I2C SDA | **PB7** |
| I2C SCL | **PB6** |
| UART TX | **PA9** |
| UART RX | **PA10** |

В коде используется калибровка **32 V / 1 A** (`setCalibration_32V_1A`).

## Сборка

```bash
cd rov_test_ina219
pio run
pio run -t upload
pio device monitor -b 57600
```

При ошибке инициализации в лог выводится подсказка проверить I2C.
