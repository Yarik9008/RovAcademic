# Gamepad — пульт управления ROV

Прошивка пульта: считывает два аналоговых джойстика и восемь кнопок, фильтрует показания фильтром Калмана и периодически отправляет пакет команд по UART (`Serial1`) на бортовой контроллер. Между пультом и бортом физически используется **RS-422** (к `PA9`/`PA10` на стороне МК подключается трансивер).

## Платформа

| Параметр | Значение |
|----------|----------|
| МК | STM32F103C8T6 |
| Частота | 72 МГц |
| Framework | Arduino (STM32) |
| ADC | 12 бит (0–4095) |
| Загрузка | WCH-Link + OpenOCD (custom) |

## Распиновка

### Джойстики (аналоговые входы)

| Ось | Пин | Инверсия | Коэффициент вклада |
|-----|-----|----------|--------------------|
| Джойстик 1 X | PA3 | нет | 0 (не используется) |
| Джойстик 1 Y | PA4 | да | 0.7 |
| Джойстик 2 X | PA5 | да | 0.5 |
| Джойстик 2 Y | PA6 | нет | 0.7 |

### Кнопки (INPUT_PULLUP, активный LOW)

| Кнопка | Пин | Назначение |
|--------|-----|------------|
| BUTTON1 | PA15 | Камера (пара с B2) |
| BUTTON2 | PB3 | Камера (пара с B1) |
| BUTTON3 | PB4 | Захват (пара с B4) |
| BUTTON4 | PB5 | Захват (пара с B3) |
| BUTTON5 | PB6 | Свет (пара с B6) |
| BUTTON6 | PB7 | Свет (пара с B5) |
| BUTTON7 | PB8 | Дополнительная |
| BUTTON8 | PB9 | Дополнительная |

Кнопки 1–6 работают **попарно**: одновременное нажатие не даёт эффекта, одиночное — выдаёт **-1** или **1**. Кнопки 7, 8 — простые (0 или 1).

### Прочее

| Функция | Пин |
|---------|-----|
| UART TX | PA9 |
| UART RX | PA10 |
| LED статус | PC13 |

## Обработка джойстиков

1. **Считывание** `analogRead()` (12 бит, 0–4095).
2. **Фильтр Калмана** — отдельный экземпляр на каждую ось (Q = 25, R = 20).
3. **Калибровка нуля** — при старте считывается текущее положение как центр.
4. **Мёртвая зона** — ±250 единиц ADC от центра → 0.
5. **Коэффициент вклада** — масштабирует отклонение (см. таблицу выше; `stick1_x = 0` означает, что ось X первого джойстика не участвует).
6. **Нормализация** в диапазон **1000–2000** (центр 1500).
7. **Инверсия** — если задана, значение зеркалится относительно 1500.

## Выходной протокол (Serial1)

Каждые **20 мс** (`DATA_INTERVAL`) отправляется строка из 9 полей через пробел, терминатор `\n`, скорость **57600** бод:

```
joy1X joy1Y joy2X joy2Y CAM GRIP LED B7 B8
```

| Поле | Тип | Диапазон | Описание |
|------|-----|----------|----------|
| joy1X | int | 1000–2000 | Ось X джойстика 1 |
| joy1Y | int | 1000–2000 | Ось Y джойстика 1 |
| joy2X | int | 1000–2000 | Ось X джойстика 2 |
| joy2Y | int | 1000–2000 | Ось Y джойстика 2 |
| CAM | int | -1, 0, 1 | Команда наклона камеры |
| GRIP | int | -1, 0, 1 | Команда захвата |
| LED | int | -1, 0, 1 | Команда освещения |
| B7 | int | 0, 1 | Кнопка 7 |
| B8 | int | 0, 1 | Кнопка 8 |

## Отладка

При `DEBUG = true` данные дублируются в **USB Serial** (`Serial`) с именованными полями:

```
joy1X:1500 joy1Y:1320 joy2X:1500 joy2Y:1680 CAM:0 GRIP:1 LED:0 B7:0 B8:0
```

## Тестовый режим

Флаг `TEST_ROBOT = true` в `config.h` подставляет фиксированные значения `joy1Y = 1250`, `joy2Y = 1750` — для проверки работы моторов без оператора.

## Ключевые параметры (`config.h`)

| Параметр | Значение | Описание |
|----------|----------|----------|
| `DEAD_ZONE` | 250 | мёртвая зона (единицы ADC) |
| `KALMAN_Q` | 25.0 | шум процесса |
| `KALMAN_R` | 20.0 | шум измерения |
| `DATA_INTERVAL` | 20 мс | период отправки (~50 Гц) |
| `BITRATE` | 57600 | скорость UART |

## Сборка и прошивка

Из корня репозитория `rov_academic`:

```bash
cd Software/gamepad
pio run              # сборка
pio run -t upload    # прошивка через WCH-Link + OpenOCD
pio device monitor -b 57600
```

> В `platformio.ini`: `build_dir = ${sysenv.TEMP}/pio_build/gamepad` (обход проблем `ld` на путях с кириллицей; на Linux при необходимости `export TEMP=/tmp`). Команда загрузки использует **`$SOURCE`** (путь к `firmware.bin` текущей сборки) и конфиг [openocd/wch-link.cfg](openocd/wch-link.cfg).
