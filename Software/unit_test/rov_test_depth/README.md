# rov_test_depth — датчик давления MS5837

Тест датчика **MS5837** (давление, температура, расчётная глубина) на **STM32F103** Blue Pill. Библиотека **MS5837** лежит в `src/` (`MS5837.h` / `MS5837.cpp`). Вывод — **USB Serial** (115200 бод).

## Платформа

| Параметр | Значение |
| -------- | -------- |
| Board | `bluepill_f103c8` |
| Загрузка | DFU |
| I2C | `Wire.begin()` — стандартные пины для STM32duino |

## Подключение

| MS5837 | STM32 |
| ------ | ----- |
| VCC | 3.3 V |
| GND | GND |
| SDA | **PB7** |
| SCL | **PB6** |

Плотность жидкости в коде: **997** кг/м³ (пресная вода); при старте выполняется **калибровка нулевой глубины** (`calibrateSurface()`).

## Сборка

```bash
cd Software/unit_test/rov_test_depth
pio run
pio run -t upload
pio device monitor -b 115200
```

## Поведение

После инициализации в порт идут колонки: давление (мбар), температура (°C), глубина (м). Опрос **неблокирующий**; при отсутствии нового кадра повторяются последние валидные значения.

Подробнее об API см. комментарии в `MS5837.h` и `src/main.cpp`.
