# rov_test_i2c — сканер шины I2C (STM32F103)

Прошивка сканирует шину **I2C** в диапазоне адресов `0x08`–`0x77` и выводит найденные устройства в **UART** на `PA9`/`PA10` (115200 бод).

## Платформа

| Параметр | Значение |
| -------- | -------- |
| Board | `genericSTM32F103C8` |
| Загрузка | DFU |

## Подключение

| Функция | Пин |
| ------- | --- |
| I2C SDA | **PB7** |
| I2C SCL | **PB6** |
| UART TX (к ПК/адаптеру) | **PA9** |
| UART RX | **PA10** |

Для просмотра лога подключите USB–UART к `PA9`/`PA10` (или используйте плату с выведенным USART1 на разъём).

## Сборка

```bash
cd Software/unit_test/rov_test_i2c
pio run
pio run -t upload
```

Монитор: `pio device monitor -b 115200` на тот порт, куда выведен USART1.

## Поведение

Раз в ~1 с повторяется сканирование; в терминале — список адресов или сообщение об отсутствии устройств.
