# rov_test_imu — BNO085 (IMU)

Диагностика датчика **BNO085** по I2C: поиск на адресах `0x4A` / `0x4B`, инициализация и периодический вывод данных (rotation vector, акселерометр, гироскоп, магнитометр) в **USB Serial** (115200 бод).

## Платформа

| Параметр | Значение |
| -------- | -------- |
| Board | `bluepill_f103c8` |
| Загрузка | DFU |
| Код датчика | заголовок `BNO085.h` в `src/` |

## Подключение

| Сигнал | Пин |
| ------ | --- |
| I2C SDA | **PB7** |
| I2C SCL | **PB6** |
| Питание | 3.3 V, GND |

Частота I2C в коде — 100 kHz.

## Сборка

```bash
cd Software/unit_test/rov_test_imu
pio run
pio run -t upload
pio device monitor -b 115200
```

Если датчик не найден, в логе выводится напоминание проверить проводку.
