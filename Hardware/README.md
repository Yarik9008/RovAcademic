# Hardware

Аппаратная часть репозитория: **схемы, печатные платы, производственные данные** и вспомогательные материалы (осциллограммы).

## Платы (производственные комплекты)

Каждая плата — каталог **`PCB_<имя>`**: BOM, Pick & Place, PDF схемы; при появлении — архив **Gerber** внутри той же папки (подкаталог `gerber/` или zip рядом).

| Каталог | Назначение |
| ------- | ---------- |
| [PCB_rov_control_system/](PCB_rov_control_system/) | Борт ROV |
| [PCB_rov_gamepad/](PCB_rov_gamepad/) | Пульт |
| [PCB_rov_gripper/](PCB_rov_gripper/) | Манипулятор |

Исходники САПР (KiCad, Altium и т.д.) по желанию кладите в ту же папку или в подкаталог `cad/`.
