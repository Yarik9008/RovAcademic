# Hardware

Аппаратная часть репозитория: **схемы, печатные платы, производственные данные** и вспомогательные материалы (осциллограммы).

## Рекомендуемая раскладка

| Подкаталог | Содержимое |
| ---------- | ---------- |
| `kicad/` или `altium/` | Исходники САПР |
| `gerber/` | Выгрузки для заказа плат |
| `pdf/` | Сборочные чертежи, схемы для печати |
| [Scope/](Scope/) | Снимки осциллографа (например экспорт BMP с прибора) |

Добавляйте краткий `README.md` в папку конкретной платы (ревизия, назначение, связь с прошивкой в [Software/](../Software/)).
