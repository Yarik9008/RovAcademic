# Control System — бортовой контроллер ROV

Прошивка принимает команды от пульта по UART (`Serial1`), формирует дифференциальное управление четырьмя движителями, управляет сервоприводом камеры и захватом манипулятора. Линия пульт–борт — **RS-422**; на плате к `USART1` подключён трансивер.

## Платформа

| Параметр | Значение |
|----------|----------|
| МК | STM32F103C8T6 (Blue Pill) |
| Частота | 72 МГц |
| Framework | Arduino (STM32) |
| Загрузка | ST-Link (OpenOCD) |
| Отладка | USB CDC (`Serial`) при `DEBUG = true` |

## Распиновка

| Функция | Пин | Примечание |
|---------|-----|------------|
| MOTOR 1 | PA6 | горизонтальный, инвертирован |
| MOTOR 2 | PA5 | горизонтальный |
| MOTOR 3 | PA4 | вертикальный |
| MOTOR 4 | PA3 | вертикальный |
| Серво камеры | PA7 | |
| Серво захвата | PB0 | без сглаживания ServoSmooth |
| UART RX | PA10 | от пульта (через RS-422) |
| UART TX | PA9 | к пульту (через RS-422) |
| LED статус | PC13 | мигание каждые 100 мс |

## Входной протокол

Строка из **9 целых чисел** через пробел, терминатор `\n`, скорость **57600** бод.  
Библиотека **AsyncStream** накапливает строку, **GParser** разбирает поля.

```
joy1X joy1Y joy2X joy2Y CAM GRIP LED B7 B8
```

Значения `joy*` валидируются: допустимый диапазон **1000–2000**. Если количество полей != 9 или данные вне диапазона — пакет отбрасывается.

## Миксер моторов

```
MOTOR 1 = joy2Y + joy2X − 1500     (горизонт, дифф.)
MOTOR 2 = joy2Y − joy2X + 1500     (горизонт, дифф.)
MOTOR 3 = joy1Y                     (вертикаль, прямое)
MOTOR 4 = 3000 − joy1Y              (вертикаль, инверсия)
```

Все выходные значения ограничиваются в пределах **1000–2000** мкс.

Расположение движителей (вид сверху):

```
          Вперёд (камера, манипулятор)
                  ↑
          [M1]─────────[M2]      горизонтальные
             │   ROV    │
          [M3]         [M4]      вертикальные
```

## Управление полезной нагрузкой

**Камера** — накопительное изменение позиции: каждый пакет с `CAM = ±1` смещает текущее значение на **±20 мкс** (`CAM_STEP`). Диапазон 1000–2000 мкс. Проходит через ServoSmooth (скорость 70, ускорение 0.7).

**Захват** — три дискретных положения:
- `GRIP = 1` → 2000 мкс (открыт)
- `GRIP = -1` → 1000 мкс (закрыт)
- `GRIP = 0` → 1500 мкс (центр)

Захват управляется через `writeMicroseconds` напрямую, **без** сглаживания.

## Безопасность

При отсутствии валидных данных дольше **1 секунды** (`DATA_TIMEOUT`) все моторы переходят в нейтраль (1500 мкс), захват — в закрытое положение (1000 мкс).

## Ключевые параметры (`config.h`)

| Параметр | Значение | Описание |
|----------|----------|----------|
| `SPEED_MOTORS` | 2500 | скорость изменения (ServoSmooth) |
| `ACCEL_MOTORS` | 4.0 | ускорение (ServoSmooth) |
| `SPEED_SERVO` | 70 | скорость серво камеры |
| `ACCELERATE_SERVO` | 0.7 | ускорение серво камеры |
| `CAM_STEP` | 20 | шаг изменения позиции камеры (мкс) |
| `GRIP_OPEN` / `GRIP_CLOSE` | 2000 / 1000 | крайние положения захвата |
| `DATA_TIMEOUT` | 1000 мс | таймаут потери связи |
| `SERVO_UPDATE_INTERVAL` | 10 мс | период `tick()` для ServoSmooth |

## Сборка и прошивка

```bash
cd control_system
pio run              # сборка
pio run -t upload    # прошивка через ST-Link
pio device monitor -b 57600
```

> На Windows при кириллице в пути проекта `ld` может не создать `firmware.map`. В `platformio.ini` для этого `build_dir` вынесен в `%TEMP%`.
