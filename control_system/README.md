# ROV Control System

Прошивка микроконтроллера для управления телеуправляемым подводным аппаратом (ROV). Система управляет 4 тяговыми моторами, сервоприводом камеры и манипулятором-захватом.

## Платформа

| Параметр | Значение |
|----------|----------|
| Микроконтроллер | STM32F103C8T6 (Blue Pill) |
| Частота | 72 МГц |
| Прошивка | Arduino framework |
| Загрузка | DFU (USB) |

---

## Распиновка (Pinout)

### Тяговые моторы (ESC / серво-сигнал)

| Мотор | Назначение | Пин STM32 | Инверсия |
|-------|------------|-----------|----------|
| MOTOR 1 | Горизонтальный левый | PA6 | ✓ да |
| MOTOR 2 | Горизонтальный правый | PA5 | нет |
| MOTOR 3 | Вертикальный | PA4 | нет |
| MOTOR 4 | Вертикальный | PA3 | нет |

### Сервоприводы

| Устройство | Пин STM32 |
|------------|-----------|
| Камера (pan/tilt) | PA7 |
| Манипулятор (захват) | PB0 |

### UART (связь с постом управления)

| Сигнал | Пин STM32 |
|--------|-----------|
| RX (приём) | PA10 |
| TX (передача) | PA9 |
| Скорость | 57600 бод |

### Индикация

| Сигнал | Пин STM32 |
|--------|-----------|
| LED (статус) | PC13 |

---

## Расположение двигателей (вид сверху)

```
                    Вперёд
              (камера, манипулятор)
                      ↑
              [M1]─────────[M2]
                 │   ROV    │
                 │          │
              [M3]        [M4]
```

- **M1, M2** — горизонтальные моторы (левый/правый борт). Управляют движением вперёд/назад и поворотом.
- **M3, M4** — вертикальные моторы. Управляют всплытием и погружением.
- **Камера и манипулятор** — в передней части корпуса.

## Протокол связи

### Формат входящих данных (от пульта)

Строка из 9 целых чисел, разделённых пробелом:

```
joy1X joy1Y joy2X joy2Y CAM GRIP LED B7 B8
```

| Поле | Диапазон | Описание |
|------|----------|----------|
| joy1X | 1000–2000 | Джойстик 1, ось X |
| joy1Y | 1000–2000 | Джойстик 1, ось Y (вертикаль) |
| joy2X | 1000–2000 | Джойстик 2, ось X (поворот) |
| joy2Y | 1000–2000 | Джойстик 2, ось Y (вперёд/назад) |
| CAM | -1, 0, 1 | Направление поворота камеры |
| GRIP | -1, 0, 1 | Захват: -1 закрыть, 1 открыть |
| LED | — | Резерв |
| B7, B8 | — | Резерв |

### Маппинг джойстиков на моторы

| Вход | Выход | Формула |
|------|-------|---------|
| joy2X, joy2Y | MOTOR 1 | joy2Y + joy2X − 1500 |
| joy2X, joy2Y | MOTOR 2 | joy2Y − joy2X + 1500 |
| joy1Y | MOTOR 3 | joy1Y |
| joy1Y | MOTOR 4 | 3000 − joy1Y |

### PWM-диапазон (моторы и серво)

| Параметр | Значение (мкс) |
|----------|----------------|
| Минимум | 1000 |
| Центр (стоп) | 1500 |
| Максимум | 2000 |

## Параметры в config.h

### Моторы

| Параметр | Значение | Описание |
|----------|----------|----------|
| ACCEL_MOTORS | 4.0 | Ускорение |
| SPEED_MOTORS | 2500 | Скорость изменения |

### Камера

| Параметр | Значение | Описание |
|----------|----------|----------|
| SPEED_SERVO | 70 | Скорость |
| ACCELERATE_SERVO | 0.7 | Ускорение |
| CAM_STEP | 20 | Шаг изменения позиции |

### Манипулятор

| Параметр | Значение | Описание |
|----------|----------|----------|
| GRIP_OPEN | 2000 | Открытый захват |
| GRIP_CLOSE | 1300 | Закрытый захват |
| ARM_SPEED | 200 | Скорость |
| ARM_ACCEL | 1.0 | Ускорение |
| ARM_INIT_ANGLE | 52 | Начальный угол |

### Таймауты

| Параметр | Значение | Описание |
|----------|----------|----------|
| DATA_TIMEOUT | 1000 мс | Таймаут потери связи |
| SERVO_UPDATE_INTERVAL | 10 мс | Период обновления серво |
| LED_BLINK_INTERVAL | 500 мс | Период мигания LED |

---

## Безопасность

При отсутствии данных от пульта более **1 секунды** (DATA_TIMEOUT) все моторы переходят в нейтраль (1500 мкс), захват закрывается. Это защита от потери связи.

## Сборка и прошивка

```bash
# Сборка
pio run

# Прошивка (DFU)
pio run --target upload

# Монитор порта
pio device monitor -b 57600
```
